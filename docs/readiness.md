# Job-readiness contract

A completed syllabus is not a pass. No baseline score has yet been assigned.

Application-ready for junior API/application support requires:
- Independently solve at least 6 of 8 unseen incidents within 45 minutes each, spanning Linux/network, API/auth, SQL, containers and integrations. Documentation allowed; no AI/mentor hints in scored rounds.
- Score at least 80/100 on each of two end-to-end mock interviews. Rubric: scope/triage 15; evidence 20; hypotheses/testing 20; resolution/rollback 15; validation/prevention 15; communication 15. Unsafe actions or fabricated evidence fail the round.
- Write correct SELECT/JOIN/GROUP BY queries, diagnose connection failures and explain an index plan using actual PostgreSQL output.
- Produce a concise initial customer response, progress update, resolution and engineering escalation; no unsupported ETA or claim of root cause.
- Explain the architecture in five minutes and trace one request, credential check, database operation and webhook delivery.
- Submit 8–12 verified incident reports with real sanitized evidence, including at least two investigated without hints, and one regression test per substantial fix.
- Pass a 90-minute take-home: reproduce, investigate, propose safe change, validate and write handoff.
- Demonstrate Git branch/commit/PR workflow, test execution and ability to read a small unfamiliar Python code path.

Cloud Support applications additionally require personally executed IAM/S3/network/EC2/CloudWatch scenarios, explainable infrastructure and teardown. API readiness does not imply readiness for every cloud or developer-support job.

Keep a private scorecard: date, commit, task, independent/assisted, score, evidence, weakest area, retest date. Current state: unassessed.
