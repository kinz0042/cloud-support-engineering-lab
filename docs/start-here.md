# Start here: the short outline

This is a career project, not a course completion checklist. Progress depends on what you can investigate and explain.

| Stage | What you will do | Proof before moving on |
|---|---|---|
| 1. Get ready | Check your current Windows setup, download the lab, run the local API | Explain a request, response, status code and request ID |
| 2. Investigate web/API failures | Work through Linux, network, DNS, HTTP and authentication incidents | Diagnose an unfamiliar 401/403/500 with evidence and a customer update |
| 3. Investigate data and integration failures | Use PostgreSQL, Docker, webhooks and retries | Show the failed path, root cause, safe fix and regression check |
| 4. Investigate cloud failures | Use logs, metrics, AWS IAM, S3 and networking in a controlled sandbox | Explain and resolve a cloud incident, then tear down resources |
| 5. Prepare for hiring | Complete unseen assessments, mock interviews, CV/LinkedIn and eligible applications | Meet the [readiness criteria](readiness.md) without hints |

The [full roadmap](roadmap.md) records the details. We do one learner task at a time. AI-generated scaffold is not counted as your own troubleshooting evidence.
